# Smart Market PWA

Aplicação web progressiva para gestão inteligente de compras de supermercado, comparação de preços entre estabelecimentos e automação de leitura de notas fiscais (SEFAZ-RS).

## 🚀 Funcionalidades
- **Mercado Campeão:** Cálculo automático em tempo real do supermercado com menor custo total.
- **Lista de Compras Rápida:** Seleção multi-item por toque com preços pareados lado a lado.
- **Leitor de QR Code:** Captura de Notas Fiscais diretamente pela câmera do navegador.
- **Fila de Processamento:** Acompanhamento do status de ingestão dos cupons fiscais.

## 🛠 Tech Stack
- **Frontend:** React + Tailwind CSS + Lucide Icons + `html5-qrcode`
- **Backend/API:** Google Apps Script (`API.gs`)
- **Database:** Google Sheets (`Smart_Market_DB`)
- **Hospedagem:** Vercel / Netlify
